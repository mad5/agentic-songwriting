# Commercial album rubric (Musicay)

Scores **1–5** (1 = weak, 5 = strong). Used by `album-editor` and album ANALYSIS. Pre-studio only — no audio claims.

## Dimensions

| Dimension | What to judge |
| --- | --- |
| Hook strength | Lead/single candidates have clear early hooks in lyrics/structure |
| Sequence flow | Opener invites; mid-album avoids sag; closer lands |
| Variety | Tempo feel / density / POV shift enough to avoid skip fatigue |
| Cohesion | Shared palette (STYLE-BIBLE) without clone tracks |
| Narrative fit | Concept chapters clear **or** collection thesis holds |
| Single plan | 2–3 singles distinct; not three ballads; streaming-friendly length cues |
| Runtime fit | Track count and implied lengths suit ~EP or ~LP goals |
| Skip risk | Weak mid-album tracks, filler interludes, repeated images |
| Brand / rating | Taboos and content rating match COMMERCIAL constraints |
| Export readiness | Style bible + per-track prompts usable in external tools |

## Verdict guide

| Verdict | When |
| --- | --- |
| `needs work` | Sequence or singles broken; major cohesion/skip issues |
| `polish` | Arc works; track-level lyric/style polish left |
| `strong` | Commercial shape + artistic thesis hold; minor nits only |

## Editor priorities

1. Sequence and single clarity  
2. Cohesion without sameness  
3. Per-track lyric quality (defer line edits to song-editor)  

Prefer concrete track-index fixes (`move 07 earlier`, `rewrite 04 chorus thesis`) over vague praise.
