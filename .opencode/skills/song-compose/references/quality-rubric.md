# Quality Rubric (Musicay)

Shared scoring for critics and ANALYSIS. Scores are **1–5** (1 = weak, 5 = strong).

## Dimensions

| Dimension | What to judge |
| --- | --- |
| Story fit | Lyrics/structure serve the narrative arc |
| Imagery | Concrete, fresh images; avoid cliché piles |
| Rhyme | Natural rhymes; no forced rhyme that kills meaning |
| Meter | Syllable count / stress pattern singable and consistent within sections |
| Hook | Chorus/hook memorable and on-theme |
| Style fit | STYLE.md matches BRIEF mood and lyric tone |
| Structure | Form supports tension and payoff |
| Coherence | No contradictions between BRIEF, STORY, STRUCTURE, STYLE, LYRICS |

## Per-section (rhyme critic)

For each labeled section in LYRICS (Verse, Chorus, …):

| Score | Guide |
| --- | --- |
| 1 | Broken meter or nonsense rhymes |
| 2 | Frequent forced rhymes / uneven lines |
| 3 | Acceptable; some weak lines |
| 4 | Strong; minor polish left |
| 5 | Tight, singable, intentional variation |

## Editor priorities

1. Meaning and story first
2. Singability second
3. Cleverness last

Prefer concrete line alternatives over vague advice. Critics **must not** edit `LYRICS.md` directly.
